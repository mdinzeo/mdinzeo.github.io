# Maria Dinzeo - Journalism Portfolio

A static site portfolio showcasing Maria Dinzeo's journalism work.

**Live site:** [mdinzeo.github.io](https://mdinzeo.github.io)

## Design

**Color Scheme:**
- Background: Pure white (#FFFFFF)
- Text: Near black (#1a1a1a)
- Accents: Sage green (#8b9d8a)
- Accent Dark: Deep sage (#6d8270)
- Border: Light gray (#e0e0e0)
- Hover: Off-white (#f5f5f5)

**Typography:**
- Sans-serif: System font stack (-apple-system, BlinkMacSystemFont, Segoe UI, Roboto, Oxygen, Ubuntu, Cantarell)
- Serif: Georgia, Cambria, Times New Roman (for article previews)
